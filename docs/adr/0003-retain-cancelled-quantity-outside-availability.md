# Zachowanie nieprzywróconych sztuk poza Dostępnością

Przy anulowaniu Zamówienia Rzutu administrator osobno decyduje, czy zamówione sztuki wracają do sprzedaży. Sztuki nieprzywrócone zapisujemy jako **Ilość Wycofaną**, zamiast zmniejszać dodatnią Pulę albo pozostawiać przydział przy anulowanym Zamówieniu Rzutu; dzięki temu Dostępność nie rośnie, historia decyzji pozostaje jawna, a znaczenie Puli i anulowania nie jest zacierane.
