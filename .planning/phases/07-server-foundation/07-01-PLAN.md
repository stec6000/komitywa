**1. WhiteNoise middleware (per D-06):**

```python
MIDDLEWARE = [
    "django.middleware.security.SecurityMiddleware",
    "whitenoise.middleware.WhiteNoiseMiddleware",
    "corsheaders.middleware.CorsMiddleware",
    # ... rest unchanged
]
```

**2. WhiteNoise storage backend (per D-06):**
Add after the STATIC_ROOT/MEDIA_ROOT block:
```python
STORAGES = {
    "staticfiles": {
        "BACKEND": "whitenoise.storage.CompressedManifestStaticFilesStorage",
    },
}
```

**3. DATABASE_URL support (per D-09, INFRA-02):**
Replace the hardcoded DATABASES block (lines 101-106) with:
```python
DATABASES = {
    "default": env.db("DATABASE_URL", default="sqlite:///db.sqlite3"),
}
```
This keeps SQLite for local dev (no DATABASE_URL in .env) and enables PostgreSQL in production via env var.

**4. LOGGING configuration (per D-04, D-05, INFRA-06):**
Add at the bottom of settings.py, before DEFAULT_AUTO_FIELD:
```python
LOGGING = {
    "version": 1,
    "disable_existing_loggers": False,
    "handlers": {
        "file": {
            "level": "WARNING",
            "class": "logging.FileHandler",
            "filename": BASE_DIR / "logs" / "django.log",
        },
    },
    "loggers": {
        "django.request": {
            "handlers": ["file"],
            "level": "WARNING",
            "propagate": True,
        },
    },
    "root": {
        "handlers": ["file"],
        "level": "WARNING",
    },
}
```

**5. Pre-HTTPS security settings (Claude's Discretion from CONTEXT.md):**
Add at the bottom of settings.py. These are safe to enable before HTTPS is active:
```python
# Security settings — safe before HTTPS
SECURE_CONTENT_TYPE_NOSNIFF = True
SECURE_PROXY_SSL_HEADER = ("HTTP_X_FORWARDED_PROTO", "https")
X_FRAME_OPTIONS = "DENY"

# Security settings — enable in .env AFTER HTTPS is active (Phase 8)
SECURE_SSL_REDIRECT = env.bool("SECURE_SSL_REDIRECT", default=False)
SESSION_COOKIE_SECURE = env.bool("SESSION_COOKIE_SECURE", default=False)
CSRF_COOKIE_SECURE = env.bool("CSRF_COOKIE_SECURE", default=False)
SECURE_HSTS_SECONDS = env.int("SECURE_HSTS_SECONDS", default=0)
SECURE_HSTS_INCLUDE_SUBDOMAINS = env.bool("SECURE_HSTS_INCLUDE_SUBDOMAINS", default=False)
SECURE_HSTS_PRELOAD = env.bool("SECURE_HSTS_PRELOAD", default=False)
CSRF_TRUSTED_ORIGINS = env.list("CSRF_TRUSTED_ORIGINS", default=[])
```

Note: SECURE_CONTENT_TYPE_NOSNIFF and X_FRAME_OPTIONS are always-on (no env toggle needed). The HTTPS-dependent settings default to off/empty and will be activated by .env values in Phase 8.
