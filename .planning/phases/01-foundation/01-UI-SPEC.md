# Phase 1 — UI Design Contract

> Visual and interaction contract for the foundation phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This phase builds the template skeleton (base.html, navbar, footer, cookie banner) that all future phases inherit. No content pages are built here — only the visual infrastructure.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Django templates + Bootstrap 5) |
| Preset | not applicable |
| Component library | Bootstrap 5.3.8 via CDN |
| Icon library | Bootstrap Icons via CDN |
| Font | Lora (headings) + Nunito (body) via Google Fonts CDN |

Source: RESEARCH.md Standard Stack, CONTEXT.md D-10 (Claude's Discretion — typography)

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, badge padding |
| md | 16px | Default element spacing, nav link padding |
| lg | 24px | Section padding, card inner spacing |
| xl | 32px | Layout gaps between major elements |
| 2xl | 48px | Major section breaks (header-to-content) |
| 3xl | 64px | Page-level vertical spacing (top/bottom margins) |

Exceptions: Cookie banner uses 12px vertical padding (py-3 in Bootstrap = 16px, acceptable within scale)

CSS implementation: Use Bootstrap spacing utilities (m-1 through m-5) mapped to this scale. Custom spacing via CSS custom properties where Bootstrap utilities are insufficient.

## Component Inventory (Phase 1 Scope)

This phase produces 4 template components. Each is described with its visual contract.

### 1. Navbar (`includes/_navbar.html`)

| Property | Value |
|----------|-------|
| Background | --kk-cream (#F5F0E8) |
| Height | Auto (content-driven), min 56px |
| Position | Static (scrolls with page) |
| Layout | Bootstrap `navbar navbar-expand-lg` |
| Brand text | "Kuchenna Komitywa" in Lora 20px bold, color --kk-olive-dark |
| Nav links | Przepisy, Sklep, O nas, Kontakt — Nunito 16px regular, color --kk-text |
| Nav link hover | Color transitions to --kk-olive, 200ms ease |
| Active link | Color --kk-olive, font-weight 700 |
| Cart icon | Bootstrap Icons `bi-cart3`, 20px, color --kk-text, wrapped in `<a aria-label="Koszyk">` |
| Cart badge | Pill badge, background --kk-olive, color white, font-size 12px |
| Mobile | Hamburger toggle at `lg` breakpoint (992px), Bootstrap collapse |
| Border | 1px solid --kk-beige on bottom edge |

Source: CONTEXT.md D-01 through D-04, RESEARCH.md Pattern (hamburger chosen for D-04)

### 2. Footer (`includes/_footer.html`)

| Property | Value |
|----------|-------|
| Background | --kk-cream (#F5F0E8) |
| Padding | 48px top, 24px bottom |
| Text color | --kk-text-light (#6B6B6B) |
| Font | Nunito 14px regular |
| Content | Copyright line: "2026 Kuchenna Komitywa. Wszelkie prawa zastrzezone." |
| Border | 1px solid --kk-beige on top edge |
| Layout | Centered text, single row for Phase 1 (future phases add links) |

### 3. Cookie Banner (`includes/_cookie_banner.html`)

| Property | Value |
|----------|-------|
| Position | Fixed bottom, full width |
| Background | --kk-olive-dark (#4A5A40) |
| Text color | White (#FFFFFF) |
| Font | Nunito 14px regular |
| Z-index | 1050 (above Bootstrap navbar fixed z-index) |
| Initial state | `display: none` in CSS (JS reveals if no consent in localStorage) |
| Layout | Flexbox row: text left, buttons right, vertically centered |
| Padding | 16px vertical, container width horizontal |
| Shadow | 0 -2px 8px rgba(0, 0, 0, 0.15) |

**Buttons:**

| Button | Label | Style |
|--------|-------|-------|
| Reject | "Odrzuc" | Outline white, 14px, Nunito bold, border-radius 4px |
| Accept | "Akceptuj" | Solid --kk-sage (#9CAF88), text white, 14px, Nunito bold, border-radius 4px |

**Behavior:**
- Appears on first visit (no `cookie_consent` key in localStorage)
- Click "Akceptuj" sets `localStorage.cookie_consent = "accepted"`, hides banner
- Click "Odrzuc" sets `localStorage.cookie_consent = "rejected"`, hides banner
- Never re-appears after decision made
- No page reload on button click

Source: CONTEXT.md D-05, D-06, D-07, RESEARCH.md Pattern 3

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Keyboard navigation | All interactive elements focusable, visible focus indicators (2px --kk-olive outline) |
| Skip to content | Hidden "Przejdz do tresci" link before navbar, visible on focus |
| ARIA landmarks | `<nav>`, `<main>`, `<footer>` semantic elements |
| Cookie banner ARIA | `role="alert"`, `aria-live="polite"` on banner container |
| Cart icon label | `aria-label="Koszyk"` on cart `<a>` element |
| Color contrast | Body text (#3D3D3D on #FDFBF7) = ratio 10.5:1 (WCAG AAA). Cookie text (white on #4A5A40) = ratio 7.2:1 (WCAG AAA). |
| Language | `<html lang="pl">` |
