  <name>Task 1: Patch settings.py — add SILENCED_SYSTEM_CHECKS, remove deprecated allauth lines</name>

  <action>
Make exactly two edits to backend/settings.py:

**Edit A — Add SILENCED_SYSTEM_CHECKS after line 257 (after CSRF_TRUSTED_ORIGINS).**

After this existing line:
```python
CSRF_TRUSTED_ORIGINS = env.list("CSRF_TRUSTED_ORIGINS", default=[])
```

Add the following two lines (one blank line gap, then the comment + setting):

```python

# silence W008: Apache handles HTTP→HTTPS redirect, not Django
SILENCED_SYSTEM_CHECKS = ["security.W008"]
```

Reason: `check --deploy` warns that SECURE_SSL_REDIRECT is False (W008), but Apache on MyDevil handles the redirect. Setting it True would cause a double-redirect loop. Django docs say to silence W008 when a reverse proxy handles the redirect.

**Edit B — Delete the two deprecated allauth lines at lines 160-161.**

Delete these two lines entirely (they appear consecutively):
```python
ACCOUNT_USERNAME_REQUIRED = False
ACCOUNT_EMAIL_REQUIRED = True
```

These settings are redundant since allauth 0.61+: ACCOUNT_SIGNUP_FIELDS (already on line 153) supersedes both. Keeping them produces deprecation warnings in `check --deploy`.

Do not touch any other lines. Double-check the final file still contains ACCOUNT_SIGNUP_FIELDS (line ~153) and ACCOUNT_EMAIL_VERIFICATION (line after the deleted block) intact.
