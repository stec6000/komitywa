# Phase 2 — UI Design Contract

> Visual and interaction contract for the landing and brand phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> This phase replaces the placeholder home page with a full landing page (hero, features, teasers) and adds 4 new content pages: O nas, Kontakt, Polityka prywatnosci, Regulamin. All pages inherit the Phase 1 base.html skeleton and brand CSS.

## Spacing Scale

Carried forward from Phase 1 without changes:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, badge padding |
| md | 16px | Default element spacing, card inner padding |
| lg | 24px | Card inner spacing, paragraph spacing |
| xl | 32px | CTA button padding (horizontal), layout gaps |
| 2xl | 48px | Section vertical padding (mobile), footer top padding |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Hero section: 80px vertical padding on desktop, 48px on mobile (matches `kk-section` convention from RESEARCH.md)
- Feature cards: 32px inner padding (xl token)

CSS implementation: Use Bootstrap spacing utilities where possible. Custom spacing via `kk-section` and `kk-section-alt` classes with 80px/48px pattern established in RESEARCH.md.

## Typography

Carried forward from Phase 1 without changes:

| Role | Size | Weight | Line Height | Font Family |
|------|------|--------|-------------|-------------|
| Body | 16px | 400 (regular) | 1.5 | Nunito, sans-serif |
| Label / Small | 14px | 700 (bold) | 1.4 | Nunito, sans-serif |
| Heading (h3-h6) | 20px | 700 (bold) | 1.2 | Lora, serif |
| Display (h1-h2) | 28px | 700 (bold) | 1.2 | Lora, serif |

Phase 2 additions:
- Hero headline uses Display role (28px Lora bold). May increase to 36px for visual impact on the hero only -- implemented as a `.kk-hero h1` override, not a new typography tier.
- Hero subtext (lead paragraph) uses Body role at 18px -- implemented as `.kk-hero .lead` override.
- Feature card titles use Heading role (20px Lora bold).
- Feature card descriptions use Body role (16px Nunito regular).
- Legal page body text uses Body role (16px Nunito regular).
- Legal page section headings use Heading role (20px Lora bold).

## Responsive Behavior

Using Bootstrap 5 defaults (carried forward from Phase 1):

| Breakpoint | Width | Hero Layout | Feature Cards |
|------------|-------|-------------|---------------|
| xs-md | < 768px | Single column (text above image) | Single column, stacked |
| md | >= 768px | Single column (text above image) | 3 columns (`col-md-4`) |
| lg+ | >= 992px | Two columns (text left, image right) | 3 columns (`col-md-4`) |

Hero image on mobile: Full width below text content, max-height 320px, `object-fit: cover`.

Content pages (O nas, Kontakt, Legal): Always single column, `col-lg-8 mx-auto` for readable width on desktop.

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Semantic sections | `<section>` with descriptive `aria-label` for hero, features, about teaser, CTA |
| Image alt text | All stock photos have descriptive Polish alt text (e.g., "Kolorowe wegańskie danie na talerzu") |
| Heading hierarchy | Single `<h1>` per page, sections use `<h2>`, subsections use `<h3>` |
| Link purpose | CTA links have descriptive text ("Zobacz przepisy"), not "Kliknij tutaj" |
| Focus indicators | All interactive elements have visible focus (2px --kk-olive outline, offset 2px) |
| Contact info | Use `<address>` element or `<dl>` for structured contact information |
| Legal page structure | Use ordered/unordered lists and heading hierarchy for scannable legal text |
| Color contrast | Body text (#3D3D3D on #FDFBF7) = 10.5:1 (AAA). CTA text (white on #6B7F5E) = 4.6:1 (AA). Feature icon (#6B7F5E on #F5F0E8) = 3.4:1 (decorative, acceptable). |
