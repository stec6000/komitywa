  <how-to-verify>
Complete these steps in order:

**Step 1: Deploy Plan 01 code to production**
```bash
ssh user@mydevil
cd ~/domains/kuchennakomitywa.pl
./deploy.sh
```
The deploy script will run migration 0002_update_site_object (sets Site to kuchennakomitywa.pl).

**Step 2: Set Brevo SMTP env vars on production**
Edit `.env` on the production server and set these 6 values (per D-10 through D-15):
```
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp-relay.brevo.com
EMAIL_PORT=587
EMAIL_USE_TLS=True
EMAIL_HOST_USER=<your Brevo SMTP login>
EMAIL_HOST_PASSWORD=<your Brevo SMTP key>
```

Get SMTP credentials from: Brevo Dashboard -> SMTP and API -> SMTP tab.

**Step 3: Restart the application**
```bash
touch ~/domains/kuchennakomitywa.pl/public/tmp/restart.txt
```

**Step 4: Send a test email from production Django shell**
```bash
cd ~/domains/kuchennakomitywa.pl
source .venv/bin/activate
python manage.py shell -c "
from django.core.mail import send_mail
from django.conf import settings
send_mail('Test Brevo', 'If you see this, SMTP works.', settings.DEFAULT_FROM_EMAIL, ['YOUR_EMAIL@example.com'])
"
```
Verify the test email arrives in your inbox.

**Step 5: Configure SPF/DKIM DNS records (per D-09)**
1. Go to Brevo Dashboard -> Senders and IP -> Domains
2. Add domain `kuchennakomitywa.pl` if not already added
3. Brevo will show required DNS records (SPF TXT and DKIM TXT)
4. Add those TXT records in MyDevil Panel -> DNS for kuchennakomitywa.pl
5. Wait for DNS propagation (can take up to 48h, usually much faster)
6. Click "Verify" in Brevo dashboard

Note: DNS propagation may take time. You can proceed to Task 2 even if not yet verified -- emails will still send, they just may be less trusted until SPF/DKIM is confirmed.
