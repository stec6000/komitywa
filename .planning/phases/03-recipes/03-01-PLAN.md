   - `title`: CharField(max_length=200)
   - `slug`: SlugField(max_length=200, unique=True)
   - `category`: ForeignKey(Category, on_delete=models.SET_NULL, null=True, blank=True, related_name="recipes")
   - `description`: TextField(help_text="Krotki opis (1-2 zdania) -- wyswietlany na karcie")
   - `ingredients_text`: TextField(help_text="Skladniki -- kazdy w nowej linii")

   - `image`: ImageField(upload_to="recipes/", blank=True, null=True, help_text="Zdjecie przepisu")
   - `is_published`: BooleanField(default=True)
   - `created_at`: DateTimeField(auto_now_add=True)
   - `updated_at`: DateTimeField(auto_now=True)
   - Meta: verbose_name="Przepis", verbose_name_plural="Przepisy", ordering=["-created_at"]
   - `__str__` returns self.title
   - `save()` override: if not self.slug, set self.slug = slugify(self.title), then call super().save()
   - Import `from django.utils.text import slugify`

4. Create `recipes/admin.py` per D-06 / PRZE-06:
   ```python
   from django.contrib import admin
   from django.utils.html import format_html
   from .models import Category, Recipe

   @admin.register(Category)
   class CategoryAdmin(admin.ModelAdmin):
       list_display = ["name", "slug"]
       prepopulated_fields = {"slug": ("name",)}

   @admin.register(Recipe)
   class RecipeAdmin(admin.ModelAdmin):
       list_display = ["title", "category", "prep_time", "is_published", "created_at", "image_preview"]
       list_filter = ["category", "is_published"]
       search_fields = ["title", "ingredients_text"]
       prepopulated_fields = {"slug": ("title",)}
       readonly_fields = ["image_preview", "created_at", "updated_at"]

       def image_preview(self, obj):
           if obj.image:
               return format_html('<img src="{}" style="max-height:60px;">', obj.image.url)
           return "---"
       image_preview.short_description = "Podglad"
   ```
