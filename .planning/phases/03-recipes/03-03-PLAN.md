
The `recipe_detail` function must:

1. Fetch the recipe: `recipe = get_object_or_404(Recipe, slug=slug, is_published=True)`

2. Build the Schema.org JSON-LD dict:
   ```python
   schema = {
       "@context": "https://schema.org",
       "@type": "Recipe",
       "name": recipe.title,
       "description": recipe.description,
       "prepTime": f"PT{recipe.prep_time}M",
       "recipeIngredient": [
           line.strip()
           for line in recipe.ingredients_text.splitlines()
           if line.strip()
       ],
       "recipeInstructions": [
           {"@type": "HowToStep", "text": step.strip()}
           for step in recipe.steps_text.splitlines()
           if step.strip()
       ],
       "datePublished": recipe.created_at.date().isoformat(),
       "author": {"@type": "Organization", "name": "Kuchenna Komitywa"},
   }
   if recipe.image:
       schema["image"] = request.build_absolute_uri(recipe.image.url)
   ```

3. Serialize with `mark_safe` to prevent Django auto-escaping:
   ```python
   schema_json = mark_safe(json.dumps(schema, ensure_ascii=False))
   ```

4. Return render with context: `{"recipe": recipe, "schema_json": schema_json}`

Full function signature: `def recipe_detail(request, slug):`
